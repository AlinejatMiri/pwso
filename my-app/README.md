# PWSO Website

This is the Vite React application for the Poor Women Support Organization website.

## Run locally

```sh
npm install
npm run dev
```

Build for production with `npm run build`, then preview the result with `npm run preview`.

## React source

- `src/main.jsx` mounts the React application.
- `src/App.jsx` selects the page for the current route.
- `src/components/` contains the shared site layout, navigation, page hero and card components.
- `src/pages/` contains one JSX component for each page: Home, About, Leadership, Programs, Priorities, Projects, Resources, News, Careers, Partnerships, Contact and Not Found.
- `public/assets/css/` and `public/assets/img/` contain the website styles and media.
